🐛 CORREÇÕES DE BUGS

1. API Open-Meteo - Erro 400 Bad Request
   Problema: surface_pressure não é parâmetro válido para daily
   Solução: Usar surface_pressure_mean para daily

2. Detecção de Ciclones - Falsos Positivos
   Problema: Classificava pressão baixa (altitude) como ciclone
   Solução: Exigir ventos fortes também (>90 km/h para extreme)
   Lógica: Pressão baixa isolada = altitude, não evento extremo

3. Supabase - Erros de Conexão (P1017)
   Problema: Server closed connection durante refresh token
   Solução: Retry com backoff exponencial + reconexão automática

4. Supabase - Pool Esgotado
   Problema: Muitas queries de autenticação
   Solução: Cache agressivo (reduz ~80% das queries)

5. Backend - req.body undefined (500 Internal Server Error)
   Problema: Middleware express.json() estava faltando
   Solução: Adicionado express.json() e express.urlencoded()
