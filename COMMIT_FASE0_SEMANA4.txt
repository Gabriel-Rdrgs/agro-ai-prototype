🎯 OBJETIVO
Finalizar a FASE 0 com integração de três APIs essenciais para dados agrícolas:
- SoilGrids (ISRIC): Dados de solo por coordenadas
- ZARC (MAPA): Zoneamento Agrícola de Risco Climático
- IBGE SIDRA: Dados de produção agrícola (endpoints REST)

📦 ARQUIVOS CRIADOS

1. ai-service/services/data_sync/soilgrids_service.py
   - Serviço para buscar propriedades do solo via API REST do ISRIC
   - Cache com @lru_cache (100 localizações)
   - Validação de dados antes de retornar
   - Suporte a múltiplas profundidades (0-5cm, 5-15cm, 15-30cm)
   - Propriedades: argila, areia, silte, carbono orgânico, pH, densidade

2. ai-service/services/data_sync/zarc_service.py
   - Serviço para buscar dados do ZARC (Zoneamento Agrícola)
   - Download automático de CSV do portal Dados Abertos do MAPA
   - Cache com @lru_cache (10 consultas)
   - Filtros por produto, estado e cultivar
   - Busca janelas de plantio ideais

3. ai-service/routers/soil.py
   - Endpoint GET /api/v1/soil/properties (dados de solo por Lat/Long)
   - Endpoint GET /api/v1/soil/summary (resumo múltiplas profundidades)
   - Integração com SoilGridsService

4. ai-service/routers/zarc.py
   - Endpoint GET /api/v1/zarc/planting-windows (janelas de plantio)
   - Endpoint GET /api/v1/zarc/ideal-period (período ideal)
   - Integração com ZARCService

5. ai-service/routers/production.py
   - Endpoint GET /api/v1/production/data (dados de produção IBGE)
   - Endpoint GET /api/v1/production/summary (resumo últimos anos)
   - Integração com IBGEScraper existente

🔧 DETALHES TÉCNICOS

SoilGrids (ISRIC):
- URL: https://rest.isric.org/soilgrids/v2.0
- Timeout: 15s
- Cache: LRU com 100 entradas
- Validação: coordenadas, valores positivos

ZARC (MAPA):
- Fonte: CSV do portal Dados Abertos (https://dados.agricultura.gov.br)
- Timeout: 30s para download
- Cache: LRU com 10 entradas
- Processamento: pandas para leitura e filtragem

IBGE SIDRA:
- Fonte: API IBGE SIDRA (https://apisidra.ibge.gov.br/)
- Tabela: 1612 (Lavouras Temporárias)
- Produtos: Tomate, Soja, Milho
- ETL: Já existente (ibge_scraper.py), apenas exposto via REST
