# 🌾 Sistema de Arbitragem Agrícola Inteligente

## 📋 Descrição
Plataforma de IA que identifica oportunidades de arbitragem no mercado agrícola através de análise climática e de preços regionais.

## 🗂️ Estrutura do Projeto
agro-ai-prototype/

├── frontend/ # React app (mapa interativo + dashboard)

├── backend/ # Node.js API (dados e lógica)

├── data/ # GeoJSON e dados mockados

└── docs/ # Documentação do projeto

## 🛠️ Stack Tecnológico
- **Frontend:** React.js + Leaflet.js + Chart.js
- **Backend:** Node.js + Express
- **Banco:** JSON/SQLite (protótipo)
- **Deploy:** Vercel (front) + Railway (back)
