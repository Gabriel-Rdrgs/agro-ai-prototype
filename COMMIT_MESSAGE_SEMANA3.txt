Implementação completa da Semana 3 da FASE 0: Dados Climáticos Automatizados

## Script Python para Open-Meteo
- Criado sync_weather_data.py para buscar dados climáticos diariamente
- Busca dados para todas as localizações únicas da tabela Opportunity
- Coleta: temperatura (max/min), precipitação, radiação, umidade, ET0
- Validação completa de dados antes de salvar
- Suporte para buscar dados históricos (--days-back)
- Tratamento robusto de erros e logging detalhado

## Tabela no Banco de Dados
- Criado modelo WeatherData no schema.prisma
- Migration SQL criada (20251214000000_add_weather_data)
- Índices otimizados para consultas por localização e data
- Constraint único para evitar duplicatas (lat, lng, date, source)

## Job Agendado
- Criado weatherSyncJob.js para gerenciar sincronização automática
- Configurado para executar diariamente às 2h da manhã (horário de Brasília)
- Integrado no server.js com suporte a variáveis de ambiente
- Rota admin para sincronização manual (/api/admin/sync-weather)
- Configurável via WEATHER_SYNC_SCHEDULE e ENABLE_WEATHER_SYNC

## Validação de Dados
- Validação de coordenadas (lat/lng dentro de faixas válidas)
- Validação de temperaturas (-10°C a 50°C para Brasil)
- Validação de precipitação (0 a 500mm/dia)
- Validação de radiação (0 a 50 MJ/m²/dia)
- Validação de umidade (0 a 100%)
- Validação de ET0 (0 a 20mm/dia)
